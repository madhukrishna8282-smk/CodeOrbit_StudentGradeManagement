student grade management system using java
Student Grade Management System

Description

A simple Java console application that accepts a student's name and marks in three subjects, calculates the total and average, and displays the student's grade.

Technologies Used

- Java
- Scanner class for user input

How to Run

1. Open the project in Eclipse IDE.
2. Open "StudentGradeManagement.java".
3. Run the program as a Java Application.
4. Enter the student's name and marks when prompted.
